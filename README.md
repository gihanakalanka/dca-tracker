# DCA Tracker

A Dollar-Cost Averaging (DCA) tracker built with **React**, designed to help users record recurring investments, calculate average cost, and monitor portfolio performance over time.

This project is being developed with a long-term goal of becoming a full **MERN stack application**.

---

## 🚀 Project Vision

DCA (Dollar-Cost Averaging) is a widely used investment strategy where users invest fixed amounts at regular intervals regardless of asset price.

This application aims to,

- Track recurring investments
- Calculate total invested capital
- Compute total accumulated units
- Determine average cost per unit
- Provide portfolio insights in a clean UI

Future versions will include backend integration, persistent storage, and authentication.
